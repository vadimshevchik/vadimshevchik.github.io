Política de privacidad

Fecha de entrada en vigor: 23 de julio de 2026

1. Qué datos recopilamos

No recopilamos tus datos personales (nombre, correo electrónico, número de teléfono, etc.). La única información que se almacena localmente en tu dispositivo:

  • Estadísticas del juego (número de victorias y derrotas por nivel de dificultad).
  • Progreso (niveles completados, estrellas, puntuación total).
  • Configuración de la aplicación (tema, sonido, vibración, etc.).

Todos los datos se almacenan en tu dispositivo y no se envían a ningún lugar.

2. Publicidad

Utilizamos el SDK publicitario de Appodeal para mostrar anuncios. El SDK puede recopilar los siguientes datos anónimos:

  • Identificadores del dispositivo (IDFA).
  • Interacción con los anuncios (visualizaciones, clics).
  • Información del dispositivo (modelo, versión del sistema operativo, idioma, país).

Estos datos se utilizan para publicidad dirigida y análisis. Puedes gestionar la configuración de anuncios a través de los ajustes del sistema de tu dispositivo (limitar el seguimiento, restablecer el identificador publicitario).

Para más detalles, consulta la política de privacidad de Appodeal: Política de privacidad de Appodeal.

3. Compartir datos con terceros

No compartimos tus datos personales con terceros. El SDK publicitario puede compartir datos anonimizados con sus socios para mostrar anuncios. La lista completa de socios y sus políticas está disponible en el sitio web de Appodeal (enlace arriba).

4. Seguridad

Todos los datos se almacenan localmente y están protegidos por el sistema operativo del dispositivo.

Nos preocupamos por tu privacidad.
