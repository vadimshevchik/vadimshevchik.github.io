Politique de confidentialité

Date d'entrée en vigueur : 23 juillet 2026

1. Quelles données nous collectons

Nous ne collectons pas vos données personnelles (nom, e-mail, numéro de téléphone, etc.). Les seules informations stockées localement sur votre appareil :

  • Statistiques de jeu (nombre de victoires et de défaites par niveau de difficulté).
  • Progression (niveaux terminés, étoiles, score total).
  • Paramètres de l'application (thème, son, vibration, etc.).

Toutes les données sont stockées sur votre appareil et ne sont envoyées nulle part.

2. Publicité

Nous utilisons le SDK publicitaire Appodeal pour afficher des annonces. Le SDK peut collecter les données anonymes suivantes :

  • Identifiants de l'appareil (IDFA).
  • Interaction avec les unités publicitaires (vues, clics).
  • Informations sur l'appareil (modèle, version du système d'exploitation, langue, pays).

Ces données sont utilisées pour la publicité ciblée et l'analyse. Vous pouvez gérer vos paramètres publicitaires via les paramètres système de votre appareil (limiter le suivi publicitaire, réinitialiser l'identifiant publicitaire).

Pour plus de détails, consultez la politique de confidentialité d'Appodeal : Politique de confidentialité d'Appodeal.

3. Partage de données avec des tiers

Nous ne partageons pas vos données personnelles avec des tiers. Le SDK publicitaire peut partager des données anonymisées avec ses partenaires pour la diffusion d'annonces. Une liste complète des partenaires et leurs politiques est disponible sur le site d'Appodeal (lien ci-dessus).

4. Sécurité

Toutes les données sont stockées localement et protégées par le système d'exploitation de l'appareil.

Nous respectons votre vie privée.
